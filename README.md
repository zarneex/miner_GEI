# miner_GEI — панель майнинга для Windows

Настольное приложение на **PySide6**: включает и выключает GPU- и CPU-майнинг,
держит температуру и обороты, считает доход в рублях и долларах, показывает
историю и графики. Одна панель вместо батников и восьми окон консоли.

Проверено на **Windows 11 + RTX 5070 12 GB + Ryzen 7 9800X3D**. Второй
пользователь работает на **RTX 5070 + Ryzen 7 7800X3D** — 8 ядер / 16 потоков;
диапазон «Потоков» строится от числа логических процессоров машины (у обоих 2–16).

> ⚠️ Это домашний инструмент, а не продукт с поддержкой: он трогает настройки
> видеокарты и схемы питания Windows. Что именно и как возвращается — в разделе
> [«Безопасность»](#безопасность-что-приложение-меняет-и-как-возвращает).

## Что умеет

- **GPU**: запуск `krig-miner` (Pearl PRL / Quantus QTC), авто-выбор монеты по
  доходности, лимит мощности (175–250 Вт), потолок оборотов кулера, ограничитель
  температуры с шагом 10 Вт и мягкой остановкой.
- **CPU**: `xmrig` (Monero RandomX), смена числа потоков и доли CPU **без
  перезапуска** (HTTP API + Job Object), термогувернатор по потолку частоты.
- **Учёт**: доход за сеанс, час, сутки, неделю, месяц, всё время; «сейчас ₽/час»
  по последним 10 минутам реальной работы; свет по тарифу; баланс кабинета
  Kryptex по куке; поминутная история в CSV и графики.
- **Ночь**: гашение мониторов по простою и кнопка «Погасить сейчас».
- **Железо после выхода**: кулер в авто, клоки и лимит мощности к заводским,
  схема питания Windows — как была (см. ниже).

## Требования

| Что | Версия / замечание |
|---|---|
| Windows | 10 или 11 x64 |
| Python | 3.11+ (проверено на 3.14) |
| PySide6 | 6.6+ (проверено 6.11.1) |
| NVIDIA | драйвер с `nvidia-smi` в `C:\Windows\System32` |
| Майнеры | `krig-miner.exe` и `xmrig.exe` — **в репозиторий не входят** |
| Права | администратор: иначе MSR и смена схемы питания недоступны |

Установка зависимостей:

```bat
C:\Python314\python.exe -m pip install -r requirements.txt
```

## Раскладка: MINER_ROOT

Приложение не хранит бинарники и данные рядом с кодом. По умолчанию корень —
`W:\mining`, переопределяется переменной окружения `MINER_ROOT`:

```
%MINER_ROOT%\
  config.json              общий конфиг (секция app — настройки GUI)
  scripts\minerctl.py      движок CLI (если есть — берётся он, иначе встроенный engine/)
  krig\krig-miner.exe
  xmrig\xmrig-6.26.0\xmrig.exe
  logs\                    журналы майнеров и приложения
  data\                    история, totals.json, модели гувернатора
```

Первый запуск:

1. Скопируйте `config.example.json` в `%MINER_ROOT%\config.json`.
2. Впишите свой логин Kryptex (`kryptex_user`, формат `логин/воркер`) — или
   сделайте это прямо в окне приложения, поле **«Кошелёк»**.
3. Положите `krig-miner.exe` и `xmrig.exe` по путям выше.
4. Запустите:

```bat
pythonw.exe main.py
```

`pythonw.exe` — без окна консоли. `start.vbs` делает то же двойным кликом.

## Кошелёк и куки

- **Кошелёк** — поле слева от кнопок; пишется в `kryptex_user` и `xmrig.user`.
  Применяется при следующем старте майнера (перезапустите раздел «Вкл»).
- **Куки** — только чтобы карточка «Баланс сайта» показывала сумму кабинета
  Kryptex. Пул не принимает куку кабинета (403), поэтому баланс разбирается из
  HTML `kryptex.com/site/balance`. Кука живёт ~2 недели, хранится в
  `app.balance.headers.Cookie` и **в репозиторий не попадает**.
- Кнопки-иконки (✓ сохранить, ↶ откатить) появляются только когда поле реально
  изменено.

## Безопасность: что приложение меняет и как возвращает

| Что меняется | Когда | Как возвращается |
|---|---|---|
| Лимит мощности карты (`nvidia-smi -pl`) | старт GPU, ограничитель | 250 Вт (заводской максимум), `gpu_cleanup` при выходе |
| Политика кулера (NVML «fixed») | потолок оборотов | авто-политика в `FanKeeper.release` и чистильщике |
| Клоки GPU (`-lgc/-lmc`) | не ставит; сбрасывает `-rgc/-rmc` | заводская таблица |
| Схема питания Windows (`PROCTHROTTLEMIN/MAX`) | только при работающем CPU-майнинге | исходные значения из `data/power-backup.json` при стопе; после краха — при следующем старте |
| Доля CPU (Job Object) | лимит «Нагрузка ЦП» | снимается закрытием job'а вместе с процессом |
| Автообновления Windows | только функцией «закрыть всё лишнее» — она **выключена** | `Cleaner.restore()` при старте |

Проверить на своей машине, что после выхода всё как прежде:

```bat
python tools\check_restore.py snapshot notes\state-before.json
:: запустить приложение, дать майнингу поработать, закрыть
python tools\check_restore.py snapshot notes\state-after.json
python tools\check_restore.py compare notes\state-before.json notes\state-after.json
```

На тестовой машине цикл «запуск → GPU 240 Вт / кулер 60 % → закрытие» вернул
схему питания 5/100 %, лимит 250 Вт и авто-политику кулера — сравнение PASS.

## Выключенные функции

- **«Ночь: закрыть всё лишнее»** — заблокирована. Функция крайне нестабильна:
  принудительно закрывает чужие процессы и останавливает службы Windows Update,
  на практике роняет само приложение-майнер. Нужна переработка, включать смысла
  нет. Код помечен в `minerapp/cleanup.py` и `minerapp/ui.py`.
- **«Ночной режим: тихо (175 Вт, кулер 55 %)»** — заблокирован по просьбе
  владельца: перезапускал майнер и менял лимит/обороты на ходу. Те же значения
  задаются вручную: «Лимит мощности» 175 Вт и «Макс. вентиляторы» 55 %.

## 100 % процессора

Галочка **«Разрешить 100 % (полный PBO)»** включена по умолчанию: со снятой
приложение режет потолок частоты до 99 % и меняет схему питания — это ломает
обычное поведение ПК (после выхода схема может остаться срезанной). 100 % стоит
+40 Вт за +0–5 % хешрейта и даёт ~90 °C; кто готов — снимайте осознанно.

## Тесты

Тесты строят окно offscreen и подменяют железо, сеть и запись конфига:

```bat
set MINER_NO_AUTOSTART=1
python tools\test_credentials.py
python tools\test_night_toggles.py
python tools\test_governor.py
python tools\test_gui_governor.py
python tools\test_gpu_guard.py
python tools\test_cleanup.py
python tools\test_cookie.py
python tools\test_cards.py
python tools\test_tray_close.py
```

`MINER_NO_AUTOSTART=1` обязателен: иначе тест поднимет боевой майнер и погасит
работающий. Живые проверки (железо, скриншоты) лежат в `tools/` отдельно.

## Структура

```
main.py                 запуск QApplication, лог необработанных исключений
minerapp/               окно, движки, метрики, история, графики
  ui.py                 всё окно (виджеты, обработчики, трей)
  engine.py             процессы krig/xmrig, мягкий стоп
  governor.py           термогувернатор CPU (потолок частоты)
  fan.py, gpu_guard.py  кулер и лимит мощности
  balance.py, rates.py  баланс кабинета, курсы
  paths.py, config.py   пути (MINER_ROOT) и общий config.json
  assets/*.svg          иконки кнопок
engine/minerctl.py      встроенная копия CLI-движка майнинга
tools/                  тесты, пробы, проверка обратимости, скриншоты
```
